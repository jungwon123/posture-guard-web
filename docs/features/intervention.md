## 목적

BAD 상태가 길어질수록 개입 강도를 올린다. 즉시 강한 알림은 피로해서 꺼버리게 되므로, 무시 가능한 신호부터 시작한다. 코드: 메인 루프의 전이 블록(`state != prev`)과 `if state == "BAD":` 블록, `notify()`.

## 채널 2개

- **창 내 연출** (테두리·비네트): 창이 보일 때만. 미니 모드(`h`)에선 생략.
- **macOS 알림 센터** (`notify()` — osascript): 창을 숨겨도 도달. 백그라운드 감시의 핵심 채널.

## 에스컬레이션 사다리 (BAD 지속 시간 기준)

| 단계 | 시점 | 연출 |
|---|---|---|
| 1 | BAD 진입 즉시 | OS 알림 + 사운드 / 얇은 빨간 테두리 (창 내) |
| 2 | `ESCALATE_NOTIFY` 경과 | OS 재알림 + 시스템 벨 1회 (`esc_fired` 플래그로 1회 보장) / 테두리 두꺼워짐 |
| 3 | `ESCALATE_VIGNETTE` 경과 | 비네트 — 화면 가장자리를 어둡게 (창 내 전용) |
| 복귀 | BAD→GOOD 전이 | "자세 복귀" 확인 알림 1회 |

- GOOD 복귀 시 모든 창 내 연출 즉시 해제 (상태 기반이므로 별도 해제 로직 없음). `esc_fired`는 전이 시 리셋.
- 지속 시간은 `sm.state_since` 기준 — 개입 로직에 자체 타이머를 두지 않는다
- 알림은 **상태 전이·에스컬레이션 시점에만** 발사 — 프레임마다 발사 금지 (스팸 방지)

## 경계 / 비목표

- 화면 전체 오버레이·집중 모드 연동은 비목표 (제품화 단계 과제).
- OS 알림은 macOS 전용 (osascript). 타 플랫폼 이식 시 이 계층만 교체.
- 개입 강도·시점 값은 `posture_guard.py` 튜닝 블록 참조.
