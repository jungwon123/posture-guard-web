# 판정 임계값 선정 — 논문 3편 교차 근거 (2026-07-23 적용)

> 적용 커밋 기준. 발표 Q&A "임계값은 어떻게 정했나요?"의 답이 이 문서다.
> 참조 논문: ① JIIBC 2024(한국공학대 — CVA 신호등·상관분석) ② JAICT 2025(동서대 — 앉은 학습자세 임계값·시간 파라미터, 정확도 94.3%) ③ KIIT 2026(한양여대 하호진 — 귀·어깨 다중지표, Dfhd·CVA, 오차 5% 이내)

## 적용된 값 (프로덕트 전체 — 플래그 없음)

| 파라미터 | 이전 → 적용 | 근거 |
|---|---|---|
| 어깨 기울기 시작 (posture3d TILT_MARGIN_DEG) | 3° → **4°** | ③ 귀-어깨 수직거리 비율 ±10% ≈ 2~4°, ② 화면좌표 0.05 ≈ 7~10° — 두 근거의 교집합. 램프 최대 14° 유지로 ②의 경계(8°)가 중턱에 위치 |
| 거북목 시작 (FORWARD_MARGIN) | 0.10 → **0.13** | ③ 정상 경계 Dfhd 5.5cm ≈ 0.145·어깨너비(38cm 기준) — 미세 기울임 오탐 완화 |
| 거북목 만감점 램프 (FORWARD_FULL) | +0.30 → **+0.12** | ③ 임상 '심각' 8cm ≈ 0.21. 이전엔 편차 0.40(≈15cm)에야 만감점 = 심각 거북목에 감점 37%뿐이던 미정렬을 교정 — 0.25(≈9.5cm)에서 만감점 |
| BAD 진입 지속 (core BAD_ENTER_SUSTAIN) | 7s → **8s** | ② 15초 단일 알림 ↔ 우리는 CAUTION(2.5s 무음 조기경고) 보유 — 중간값. 필기 오탐(QC V1) 완화 방향 |
| 자리비움 판정 (AWAY_AFTER) | 10s → **15s** | ② 검증값 채택 — 물건 줍기·잠깐 가림 오탐 감소 |

유지: HEAD_DROP_DEADZONE 25%(②의 '엎드림'은 더 큰 낙폭 — 우리 완화가 과하지 않음 확인), PITCH_MARGIN 35°(논문 비교근거 없음 — 자체 실측 영역), LATERAL ±0.12(③의 ΔX 데이터 내부 모순으로 판단 보류), CAUTION 2.5s(③의 4단계 중증도 분류가 다단계 구조를 지지).

## 단위 환산 노트

- ② 는 정규화 **화면 좌표 절대값**이라 카메라 거리에 의존 → 어깨너비로 나눠 각도/비율화해 비교 (어깨 높이차 0.05 ÷ 화면상 어깨너비 0.30~0.40 ≈ 7~10°).
- ③ 의 cm 값은 성인 어깨너비 ≈38cm로 나눠 우리 정규화 단위로 변환 (5.5cm→0.145, 8cm→0.21).
- 우리 지표는 전부 **개인 캘리브 기준 대비 편차 + 어깨너비 정규화**라 재캘리브 없이 즉시 적용됨.

## 벤치마크 (M3 목표치)

②의 자세 인식 정확도 **94.3% / 재현율 90.2%** = 동일 도메인 선행 수준. M3 실사용 오탐률 튜닝의 통과 기준선으로 사용.

## 남은 확인 (실기기)

- FORWARD_FULL 축소는 "더 민감" 방향 + Z 노이즈 민감도 증가 — `?fwd=1` 디버그 오버레이로 정자세↔거북목 Δ와 노이즈 폭 실측(기존 미완 항목과 동일 세션). 노이즈가 램프 폭(0.12)에 육박하면 One-Euro minCutoff 하향 또는 FULL 0.15로 소폭 완화.
- QC 확인트랙 V1(필기)·V2(고개돌림)를 새 값 기준으로 재실측.
