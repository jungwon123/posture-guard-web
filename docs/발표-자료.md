## 1. 우리 서비스 개요

**척추요정 — "자세까지 지켜주는 열품타"**
웹캠으로 거북목·굽은 등을 실시간 감지하면서 공부 시간을 재는 웹앱(PWA). 설치 없이 링크로 열고, 홈 화면에 추가하면 앱처럼 쓴다.

- **문제**: 고등학생은 하루 10시간 가까이 앉아서 공부한다. 공부 시간을 재는 앱(열품타)은 많지만, 그 시간 동안 **몸이 망가지는 건 아무도 안 봐준다**. 거북목은 한 번 생기면 되돌리기 어렵다.
- **해법**: 공부 타이머에 자세 감지를 결합 — 앉아 있는 동안만 시간이 쌓이고(착석 기반 순공시간), 자세가 무너지면 요정이 바로 알려준다.
- **차별점 한 줄**: 열품타의 순공시간은 "폰을 안 봤다"는 간접 증거지만, 우리는 **카메라로 실제 앉아 공부한 시간**을 잰다. 그리고 "수학 할 때 유독 자세가 무너져요" 같은 리포트는 **세상에서 우리만 만들 수 있다.**
- **프라이버시 원칙(중요)**: 모든 영상 분석은 **내 기기 안에서만** 돈다(온디바이스 AI). 서버로 가는 건 "오늘 몇 분, 바른 자세 몇 %" 같은 **숫자와 닉네임뿐** — 영상·사진은 어디에도 저장·전송되지 않는다.
- **팀**: 9인 (개발 1 + 기획·디자인·QC 8) — QC 실사용 테스트, 디자인 컨셉, 기능 기획을 팀이 분담.

**[말하기]** "공부 시간을 재주는 앱은 많습니다. 그런데 그 10시간 동안 여러분의 목은 누가 지켜주나요? 저희는 타이머에 자세를 붙였습니다."

## 2. 핵심 기능

### ① 자세 감지 엔진 (기술 코어)
- 구글 MediaPipe(포즈 + 얼굴, 온디바이스)로 초당 10회 상반신 분석.
- **개인 맞춤 기준**: 시작할 때 5초 '바른 자세 등록' → 그 사람 기준 대비 편차로 판정 (체형·카메라 위치 무관).
- 신호 8종: 거북목 전방이동(깊이·홍채), 고개 숙임(얼굴 회전행렬), 머리 높이, 어깨 기울기·말림, 좌우 쏠림, 갸웃, 턱괴기.
- **홍채 절대 거리**: 사람 홍채 지름이 ~11.7mm로 일정한 점을 이용해 화면 근접·거북목을 절대 거리로 판정 (선행논문 기법 + 자체 개선 — 기기 화각 무관).
- 선행 학술논문(JIIBC 2024)과 대조해 임계값·중복감점·주의 단계 설계. ★시연: 트래킹 패널에서 신호별 막대 + 문제 부위 표시.

### ② 공부 타이머 (열품타 코어)
- **착석 기반 순공시간**: 자리를 뜨면 자동 정지. ★오늘 공부 시간 라이브 클록.
- **과목별 타이머**: 과목 칩 전환 → 과목별 시간 + **과목별 바른자세 %** 리포트.
- **오늘 목표**: 시간 + 자세 70% 이중 목표 — 달성하면 요정이 축하하고 보너스 포인트. D-Day 배지.

### ③ 요정 (감정을 담당하는 캐릭터)
- 자세가 무너지면 **아픈 부위별로 다르게** 아파한다(목/등/골반 모션) — 말풍선으로 원인을 콕 짚어 코칭.
- 포인트로 요정 스킨 10종 수집·장착(상점), 화면을 돌아다니는 도우미 요정(드래그 가능).

### ④ 함께 공부 (소셜)
- 그룹 코드로 참여 → **주간 랭킹 명예의 전당**(시상대·역대 챔피언), 실시간 접속 상태.
- **실시간 카메라 그리드**: 반 전체가 서로의 공부를 보며 독서실처럼 (옵트인 — 직접 켜야 보임).
- **콕 찌르기**: 조는 친구 깨우기 (전용 알림음 + 진동).

### ⑤ 기록·통계
- 일별 기록 + 월 캘린더 히트맵(공부할수록 진해짐 + 자세 우수일 새싹 배지).
- 시간대별 정확도·7일 막대·자세 도넛 차트, 월간 추세(선형회귀 — "한 달간 좋아지고 있나").
- 계정(이메일·구글 로그인) + 서버 동기화 — 기기를 바꿔도 기록 유지.

**[말하기]** ★라이브 시연 순서 추천: 공부 시작 → 기준 등록 → 일부러 거북목 → 요정 반응 → 과목 전환 → 목표 게이지 → (폰 2대) 그리드·콕.

## 3. 현재 개발 진행 상태

**전부 배포 완료, 실제 서비스 중** — https://posture-guard-rust.vercel.app

| 영역 | 상태 |
|---|---|
| 자세 엔진 (신호 8종 + 개인화 기준 + 논문 반영) | ✅ 완료 |
| 공부 타이머 (순공·과목·목표·D-Day) | ✅ 완료 |
| 요정 (모션 9종 × 스킨 10종, 부위별 반응) | ✅ 완료 |
| 그룹 (랭킹·실시간 그리드·콕) | ✅ 완료 |
| 계정·동기화 (이메일/구글, 멀티기기) | ✅ 완료 |
| 통계 (캘린더·차트·리포트·온보딩) | ✅ 완료 |
| QC 실사용 피드백 반영 (온보딩·안내 개선) | ✅ 1차 완료 |

**숫자로 보는 개발량**: 커밋 93개 · 프론트 코드 약 5,000줄 · React 컴포넌트 25개 · 설계 문서 17편 · 자동 테스트 45개(전부 통과)

**기술 아키텍처 (엔지니어링 포인트)**:
- 프론트: React PWA (Vercel 배포) / 백엔드: Express + PostgreSQL — **클라우드 서버(GCP VM)를 직접 구축·운영** (리버스 프록시, HTTPS, systemd, 방화벽까지 직접).
- **실시간 3단 진화 서사**: ① WebRTC P2P 연결을 시그널링 서버까지 직접 구현 → ② 업링크 N-1 구조 한계를 확인하고 SFU(중계 서버) 아키텍처로 전환 → ③ 같은 오픈소스 SFU(LiveKit)를 **우리 서버에 직접 설치·운영**까지. (다이어그램: docs/시스템-아키텍처.md)
- 선행 학술논문과 대조 분석해 판정 로직 개선 — 논문의 실패 데이터(정면 카메라 한계)에서 배워 깊이(Z)·홍채 신호로 보완.

**[말하기]** "기능만 만든 게 아니라, P2P를 직접 구현해보고 한계를 재서 아키텍처를 갈아탔고, 그 중계 서버를 오픈소스로 직접 운영하는 데까지 갔습니다."

## 4. 향후 개발 계획

**단기 (2주 내, P1 — 기획서 완료 상태)**
1. **하루 타임라인 플래너** — 몇 시에 뭘 공부했고 언제 자세가 무너졌는지 한눈에 (열품타 플래너 + 자세 오버레이 = 유일무이)
2. **리포트 공유 카드** — 오늘 기록을 이미지로 만들어 인스타 인증 ("공스타그램" 바이럴 훅, **디자인·운영은 비개발 팀원 주도**)
3. 과목 기록 서버 동기화 · 그룹 목표시간 · 데이오프(쉬어도 스트릭 유지) · 전체 주간 랭킹

**검증 (M3 — 팀 미션)**
- 팀원 8명 실사용 데이터 수집 → 오탐률 측정 → 임계값 튜닝 (QC 체크리스트 운영 중)
- 거북목 깊이 신호 실기기 부호 검증, 새 홍채 신호 체감 평가

**중장기 (P2 비전)**
- 요정 진화(누적 공부시간에 따라 성장), 학년별 전국 랭킹, 주간 자세 챌린지 운영
- 사용자가 늘면: 관리형 DB 이전, 휴식 스트레칭 콘텐츠(자세 앱만의 휴식)

**[말하기]** "다음 단계는 기능 추가가 아니라 검증입니다 — 팀원 8명이 실제로 2주간 쓰면서 오탐률을 측정하고 조정합니다. 그리고 자세 데이터라는 우리만의 자산으로 '자세까지 보이는 플래너'를 완성합니다."

### 부록 — 예상 질문 대비
- **Q. 영상 유출 위험은?** → 영상은 기기 밖으로 안 나간다(온디바이스). 그리드 영상도 중계만 되고 저장되지 않으며, 서버·DB에는 숫자만 있다.
- **Q. 정확도는?** → 개인 기준 등록 + 신호 8종 교차 + 선행논문 임계값. 남은 오탐은 M3 실사용 데이터로 튜닝 예정이라고 솔직하게.
- **Q. 열품타와 뭐가 다른가?** → 측정이 더 정직하고(착석 기반), 자세 데이터가 있다. "과목별 자세 리포트"는 우리만 가능.
- **Q. 비용은?** → 정적 호스팅 무료 + 소형 VM — 학생 예산으로 운영 가능한 구조.
