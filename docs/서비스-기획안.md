# Posture Guard — 서비스 기획안

> **한 줄 정의**: 노트북·PC 카메라로 거북목을 감지해, 자세가 무너졌을 때만 "척추요정"이 알려주고, 바른 자세를 유지하면 포인트로 보상하는 자세 관리 서비스.
> 문서 버전: v2.0 (2026-07-18) · 상태 표기: ✅ 구현됨 / 🔜 예정 / 💡 아이디어

---

## 1. 서비스 개요

### 왜 만드는가
공부·작업 중 자세가 무너지는 순간을 본인은 알 수 없다. 기존 해법은 셋 다 한계가 있다 — 시간 기반 알림(자세와 무관하게 울려서 꺼버림), 웨어러블(비용·착용 부담), 클라우드 분석(카메라 영상 유출 거부감).

### 우리의 답 3가지
1. **진짜 무너졌을 때만** — 개인 기준 대비 점수화 + "20초 지속" 판정으로 오탐을 걸러낸다
2. **점점 세게, 그리고 보상으로** — 조용한 알림에서 시작해 단계적으로 개입하고, 잘하면 포인트를 준다
3. **영상은 아무 데도 안 간다** — 모든 처리가 기기 안에서 끝난다. 저장되는 건 숫자뿐

### 타깃

| 우선순위 | 대상 | 핵심 시나리오 |
|---|---|---|
| P0 | 공부·코딩 오래 하는 학생 | 미니 창 띄워두고 공부 → 무너지면 요정이 알림 → 포인트 모아 꾸미기 |
| P1 | 재택근무자 | 하루 리포트로 습관 파악 |
| P2 | 자세 교정 중인 사람 | 주간 기록으로 교정 진행도 확인 |

## 2. 제품 형태 (플랫폼 전략)

| 형태 | 상태 | 역할 |
|---|---|---|
| 데스크톱 앱 (Python) | ✅ | 판정 로직의 **레퍼런스 구현** + 튜닝 도구 (녹화·리플레이) |
| **웹 PWA** | ✅ 1차 | **주력 배포 형태** — 링크 하나로 설치 없이 사용, 두 구현은 같은 녹화 데이터로 판정 일치 검증(패리티) |
| 태블릿 | 🔜 | 웹 버전을 스플릿 뷰로 상주 (완전 백그라운드는 플랫폼 제약) |

웹에서의 제약과 대응: 다른 앱 위 화면 연출 불가 → 알림 반복으로 대체 / 미니 모드 → **PiP**(모든 앱 위에 뜨는 작은 창)로 오히려 업그레이드.

## 3. 핵심 기능 명세

### 3.1 감지·판정 ✅
- 카메라 → AI(MediaPipe)가 코·귀·어깨 위치 추출 → 거북목 신호 4개(근접도·고개 숙임·머리 하강·어깨 말림) 계산
- **개인 캘리브레이션**: 5초간 "내 바른 자세" 측정 → 이후 그 기준 대비 0~100점
- **상태 판정**: 60점 미만 20초 지속 → 나쁜 자세 / 75점 초과 5초 → 복귀 / 10초 미검출 → 자리비움
- 판정 근거를 보여주는 **TRACKING 화면** (스켈레톤 + 신호 막대)

### 3.2 개입 (알림) ✅
- **에스컬레이션**: 진입 시 알림 1회 → 60초 지속 시 재알림+강한 소리 → 3분 시 화면 비네트(보일 때)
- **알림 커스텀**: 소리/진동/둘다/무음 · 멜로디 4종 · **내 노래 업로드**(2MB, 기기 내 저장) · 음량/진동 세기
- 복귀하면 칭찬 알림 ("요정이 기뻐해요")

### 3.3 캐릭터 — 척추요정 ✅
상태를 감정으로 번역해주는 마스코트. 헤더·PiP 미니 창·알림 문구에 등장.

🥚(기준 등록 전) → 🧚(좋음) → 🤨(나빠지는 중) → 😠(나쁨) → 🤬(60초+) → 🥰(복귀) → 💤(자리비움)

### 3.4 보상 — 포인트 경제 ✅

| 행동 | 보상 | 의도 |
|---|---|---|
| 바른 자세 1분 유지 | +1P | 핵심 행동을 직접 보상 |
| 하루 첫 실행 (출석) | +10P | 매일 켜는 습관 |
| 나쁜 자세 | 적립 정지 (차감 없음) | 벌점은 이탈을 부른다 |
| 상점: 요정 스킨(고양이·곰) 30P, 테마 색 20P | 소비처 | 포인트에 의미 부여 |

### 3.5 기록·리포트 ✅
- 상태 전이만 기록 (영상·신호 저장 없음)
- **오늘 리포트**: 총 감시 시간 / 바른 자세 % / 나쁜 자세 횟수 / 최장 연속 기록 / 오늘 포인트 + 한 줄 평가
- 🔜 주간 리포트, 추세 그래프

### 3.6 같이 쓰기 — 그룹 🔜 (설계 완료, 서버 필요)
- 열품타식: 그룹 코드 6자리로 가입 → 이번 주 "바른 자세 시간" 랭킹
- 서버로 가는 건 **집계 숫자뿐** (누적 분·포인트). 익명 닉네임. 채팅 없음
- 💡 후속: 반 대항전, 친구에게 응원 콕 찌르기

### 3.7 보류 💡
게임 요소 확장, 화면 커스텀 전체 — 브레인스토밍 구체화 카드에서 범위 확정 후 진행

## 4. 사용자 흐름 (하루)

```
아침: 링크 열기 → 출석 +10P → 카메라 시작 → (첫 사용이면 기준 등록 5초)
     → 미니 모드(PiP) 켜고 구석에 두기
공부 중: 바른 자세 → 조용히 1분마다 +1P
        무너짐 20초 → 🔔 "척추요정이 화났어요!" (내가 고른 노래로)
        고치면 5초 → 🥰 "포인트 다시 적립!"
저녁: 오늘 리포트 확인 → "바른 자세 87% · +52P" → 모은 포인트로 곰 스킨 구매
```

## 6. 프라이버시 원칙 (불변식)

> **카메라 영상은 저장·전송하지 않는다. 밖으로 나가는 데이터는 0.**

- 기기에 남는 것: 개인 기준값, 상태 전이 시각, 설정, (선택) 알림용 노래 — 전부 로컬
- 그룹 기능이 생겨도 서버 공유는 집계 숫자뿐
- 개인 데이터 파일은 저장소 커밋 자동 차단(훅)으로 이중 보호

## 7. 검증 계획과 지표

| 지표 | 목표 | 측정 방법 |
|---|---|---|
