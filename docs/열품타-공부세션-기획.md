## 1. 열품타(YPT) 공부 세션 기능 전체 맵

열품타 = "열정 품은 타이머". 2018년 출시, 한국 수험생 공부 타이머 1위 앱.
핵심 루프: **측정한다 → 기록이 쌓인다 → 남과 비교된다 → 내일 또 켠다.**

| # | 기능 | 동작 방식 | 리텐션 훅 (왜 먹히나) |
|---|------|-----------|------------------------|
| 1 | **과목별 스톱워치/타이머** | 과목을 등록하면 과목마다 고유 색상이 붙는다. 과목 옆 재생 버튼만 누르면 그 과목으로 측정 시작, 다른 과목 누르면 자동 전환. | "오늘 수학만 하고 영어를 안 했네"가 색으로 한눈에 보인다. 기록을 '모으는' 수집 심리 + 과목 밸런스 자가진단. |
| 2 | **스터디 플래너 자동 생성** | 측정된 시간이 과목 색상별 일일 타임라인(플래너)으로 자동 그려진다. 손으로 쓰는 플래너를 앱이 대신 완성. | 하루 끝에 "오늘의 완성된 플래너"를 보는 성취감. 캡처해서 인스타 '공스타그램' 인증하는 문화가 자생 → 무료 바이럴. |
| 3 | **목표 공부시간 ("목공시")** | 하루 목표 공부시간을 설정, 홈에서 달성률(진행 게이지)을 실시간 확인. 달성 시 표시. | "매일 나와의 약속"을 만들어 앱을 매일 켜게 하는 장치. 달성률 심리(90%에서 끄기 아까움). |
| 4 | **D-Day** | 수능·모의고사 등 시험일 디데이 등록, 홈·위젯·워치에 상시 노출. | 긴박감을 매일 리마인드. 타이머를 켜는 '이유'를 화면에 박아둔다. |
| 5 | **순공시간 측정** | 측정 중 화면을 끄거나 앱을 벗어나면 시간에서 제외. "책상에 앉은 시간"이 아니라 "진짜 공부한 시간"만 카운트. 하루 20시간 초과·연속 집중 9시간 초과 기록은 어뷰징으로 간주해 랭킹 불인정. | "순공시간"이라는 단어 자체를 유행시켰다. 숫자가 정직하다는 신뢰 = 비교·경쟁의 전제 조건. |
| 6 | **집중모드 / 앱 잠금** | (안드로이드) 측정 중 허용앱(계산기·사전 등 화이트리스트) 외 모든 앱 차단. 유료 '잠금 해제권'도 판매. iOS는 OS 제약으로 제한적. | 의지가 아니라 시스템으로 폰을 막아준다. 학부모·교사 신뢰 요인이기도 함. |
| 7 | **스터디 그룹** | 사용자가 만드는 무료 그룹 + 운영사가 여는 유료 '미션 그룹'. 그룹 검색·필터(출석률/공부량/캠 여부/빈자리), 가입 전 '둘러보기', 필독사항·가입조건(예: 주 45시간, 하루 7시간 의무), 출석부, 그룹 채팅+스티커, '깨우기'(안 하는 멤버 독려), 일/주/월 그룹 랭킹. | 상호 감시 + 소속감. "다들 지금 공부 중"이라는 실시간 압력. 그룹 규칙(벌금·의무시간)은 유저들이 알아서 만든 문화. |
| 8 | **실시간 공부 상태 표시** | 그룹원이 지금 공부중/휴식중인지 아이콘 또는 캠으로 실시간 표시. | 새벽에 열어봐도 누군가 공부 중 → "나도 해야지". 앱을 '보러' 들어오게 만든다. |
| 9 | **캠 스터디** | 그룹 내 실시간 캠 화면 공유. 30초 간격 자동 사진 촬영으로 공부 '증명'. PC 웹캠 버전도 제공. | 독서실의 시선을 온라인으로 재현. 증명 사진 = 신뢰 장치. |
| 10 | **전국·카테고리 랭킹** | 대입/고입/고시/공무원/편입/어학 등 같은 카테고리 유저끼리 일/주/월 실시간 랭킹. | "나와 같은 처지"끼리만 비교하니 공정하다고 느낀다. 전국 단위 경쟁 자극. |
| 11 | **통계** | 일/주/월 통계, 공부할수록 색이 진해지는 달력(히트맵), 시간대별 집중 타임라인, 과목별 비중, 최대 집중시간, 집중력 분석. | 내 공부가 '데이터'가 되는 재미. 히트맵 빈칸을 채우고 싶은 심리(잔디 심기). |
| 12 | **데이오프 / 반데이오프** | 캘린더에서 쉬는 날("데옾")을 선언. 그룹 의무시간에서 면제. 휴무권·공부시간 인정권 같은 아이템도 존재. | 쉬는 날을 '이탈'이 아니라 '제도'로 만들어 죄책감 없이 복귀하게 한다. 번아웃 이탈 방지. |
| 13 | **스터디콘 (캐릭터)** | 누적 공부시간에 따라 진화하는 캐릭터 아이콘. 스토어에서 꾸미기. | 공부시간 = 캐릭터 성장. 랭킹·그룹 화면에서 남에게 보이는 과시 요소. |
| 14 | **친구 / 응원** | 친구 추가, 친구 공부시간 실시간 확인, 응원 메시지, 시험기간 공동 목표. | 경쟁(랭킹)과 별개로 '응원' 관계를 제공 — 부담 낮은 소셜. |
| 15 | **뽀모도로** | 25분 집중 + 5분 휴식 프리셋 타이머. | 시작 장벽을 낮추는 진입 장치. |
| 16 | **커뮤니티(열정카페)·우리학교** | 카테고리별 게시판, 학교 입력 시 시간표·급식표 자동 생성. | 공부 외 체류 이유를 만들어 DAU 방어. (단, UX 분석들에선 "본질과 멀다"는 비판도.) |
| 17 | **프리미엄/수익화** | 월 구독 3,900원~프리미엄 5,900원, 연 33,000~39,900원, '불꽃' 토큰(100개 1,500원), 광고 제거, 잠금 해제권 1,100원. | 무료로 코어 루프 전부 개방 → 광고 제거·편의 기능만 과금. 학생 지갑 사정에 맞춘 소액 결제. |

**열품타 리텐션 구조 요약**: ① 정직한 측정(순공) → ② 기록의 시각화(플래너·히트맵) → ③ 사회적 비교(그룹·랭킹·실시간 상태) → ④ 복귀 장치(데이오프·스트릭). 우리가 베낄 것은 기능 목록이 아니라 이 4단 구조다.

## 2. 척추요정 현황 대비 갭 분석

척추요정의 순공시간 = **웹캠 착석 감지 기반** ("자리에 앉아 있는 동안만 카운트"). 열품타의 "화면 켜짐" 프록시보다 **더 정직한 순공 측정**이라는 점이 우리 최대 자산.

### 이미 있음 (열품타 대응 기능 보유)

| 열품타 | 척추요정 현재 구현 | 비고 |
|---|---|---|
| 순공시간 측정 | 오늘 공부 시간 라이브 타이머 (착석 감지 기반) | 측정 방식은 오히려 우위 |
| 세션 타이머 | 이번 세션 타이머 | 동등 |
| 캠 스터디 | 그룹 실시간 카메라 그리드 | 단 영상은 P2P/온디바이스, 서버 미전송 |
| 그룹 랭킹 | 주간 랭킹 + 명예의 전당(champions) | 그룹 내 한정 |
| 깨우기 | 콕 찌르기(nudges) | 동등 |
| 실시간 상태 표시 | presence (공부중 상태 + 스킨) | 동등 |
| 출석/연속 기록 | 연속 출석 스트릭 | 동등 |
| 스터디콘 | 포인트/상점 + 요정 스킨 꾸미기 | 요정은 '자세 반응 캐릭터'라 더 살아있음 |
| 통계·달력 | 일별 기록 + 월 캘린더, 통계 차트, 일/주 리포트 | 자세 % 축이 추가로 있음 |

### 부분 있음 (뼈대는 있는데 열품타식 훅이 빠짐)

| 항목 | 있는 것 | 빠진 것 |
|---|---|---|
| 월 캘린더 | 일별 기록 표시 | "공부할수록 진해지는" 히트맵 농도, 데이오프 표기 |
| 랭킹 | 그룹 내 주간 | 서비스 전체/카테고리(학년) 랭킹, 일간 랭킹 |
| 리포트 | 일/주 리포트 카드 | 캡처·공유(인증) 동선 — 공스타그램 훅 부재 |
| 그룹 | 코드 참여, 주간 랭킹 | 그룹 목표시간·가입조건·출석부 같은 '규칙' 레이어 |
| 타임라인 | 통계 차트 | 과목 색상 플래너식 하루 타임라인 |

### 없음

- **과목별 타이머/플래너** (열품타 정체성 그 자체 — 최대 갭)
- **목표 공부시간 + 달성률** (매일 켜게 하는 약속 장치)
- **D-Day**
- **데이오프** (스트릭 이탈 방지 장치)
- 뽀모도로, 친구/응원, 전국 랭킹, 커뮤니티, 시간표/급식표, 앱 잠금, 프리미엄 과금

## 3. 도입 기획 (P0 / P1 / P2)

설계 원칙:
1. **열품타 기능을 그대로 이식하지 않는다.** 모든 기능은 "자세·요정과 결합했을 때 열품타가 못 하는 것"이 있어야 채택.
2. 개발 1인 — 기존 패턴(이벤트 로그 + 일별 스냅샷 + GREATEST 병합 + accounts.data JSONB) 위에만 얹는다. 새 인프라 금지.
3. 프라이버시 불변식 유지 — 서버로 가는 것은 집계 숫자뿐.

현재 데이터 파이프라인 (기준 지식):

```
pg_events (localStorage, {t, from, to} 자세 전이 로그, 최근 2000건)
  → computeReport(events, from, to)로 모든 타이머·차트 계산
  → 1분 주기 writeDailySnapshot → pg_daily {"YYYY-MM-DD": {watched,good,caution,bad,badCount,longestGood}}
  → pushDaily → 서버 daily_stats(account_id, date, watched_sec, good_sec, …) GREATEST 병합
계정 부속 데이터(포인트·상점·출석)는 accounts.data JSONB로 스냅샷 동기화
```

### P0 — 시연 전 필수 (열품타의 코어 루프 완성)

#### P0-1. 목표 공부시간 + 달성 링 ("오늘의 약속") — 난이도 S

- **우리식 변형**: 열품타는 목표가 '시간' 하나지만, 우리는 **이중 목표** — ① 오늘 착석 공부 N시간 + ② 바른자세 M% (기본 70%). 달성 시 **요정이 praise 모션 + 보너스 포인트**(1일 1회). "시간만 채우고 자세 무너지면 요정이 아쉬워한다" = 열품타가 흉내낼 수 없는 지점.
- **UI**: 홈 타이머 주위 진행 링(시간 목표) + 링 색상으로 자세 목표 상태. 목표 미설정 시 온보딩에서 1탭 프리셋(2h/4h/6h).
- **데이터 모델**: 서버 테이블 변경 **0**.
  - 클라 `pg_goal = { dailySec, goodPct, updatedAt }` — 기존 accounts.data JSONB 스냅샷에 필드 추가(동기화 공짜).
  - 달성 판정: `pg_daily[오늘].watched >= dailySec && good/watched >= goodPct`. 보상 중복 방지는 출석 로직과 동일하게 `pg_goal_award_last`(날짜 문자열) 가드.
- **예상 효과**: DAU의 '매일 켤 이유' 확보. 열품타 목공시의 달성률 심리 + 요정 보상 루프 결합.

#### P0-2. 과목별 타이머 v1 (과목 칩 + 오늘 과목별 시간) — 난이도 M

- **우리식 변형**: 열품타는 과목별 '터치 시간'이지만, 우리는 **과목별 착석 시간 + 과목별 바른자세 %**. "국어 할 때 유독 자세가 무너진다" 같은, 세상에 없는 데이터가 나온다. 요정 리포트 멘트로 연결("수학 시간엔 허리가 꼿꼿하네요!").
- **UI**: 타이머 위 과목 칩 바(수학·국어·영어… + 추가 버튼, 과목별 색상). 칩 탭 = 현재 과목 전환. 미선택 시 '일반 공부'. 오늘 리포트에 과목별 도넛(시간 비중) + 과목별 자세 % 바.
- **데이터 모델 — pg_events를 건드리지 않는다** (핵심 설계):
  - 자세 이벤트 스트림과 **별도의 라벨 스트림**을 둔다.
    - `pg_subjects = [{id, name, color, order, archived}]` — 과목 사전. accounts.data JSONB로 동기화.
    - `pg_subj_log = [{t, id|null}]` — 과목 전환 이벤트(append-only, pg_events처럼 최근 2000건 캡). null = 과목 해제.
  - 계산: `computeSubjects(events, subjLog, from, to)` — 두 스트림을 시간순 머지해 구간별 (자세상태 × 과목) 교집합 산출 → 과목별 watched/good 합산. **AWAY 구간은 자동으로 어느 과목에도 안 잡힘** → "과목별 시간도 착석 기반"이 공짜로 성립.
  - 일별 영구화(2000건 캡 유실 대비): `pg_daily`와 같은 자리에서 1분 주기 스냅샷 `pg_daily_subj = {"YYYY-MM-DD": {"<subjectId>": {watched, good}}}` (필드별 max 병합, 동일 패턴).
  - **P0 범위는 여기까지(로컬 온리)** — 서버 동기화는 P1-1로.
- **예상 효과**: 시연 데모의 킬러 장면("과목별 자세 리포트"). 열품타 유저가 즉시 이해하는 UI라 학습 비용 0.

#### P0-3. D-Day 배지 — 난이도 S

- **우리식 변형**: 헤더에 D-Day 1개(수능/중간고사 라벨+날짜). 요정 말풍선이 가끔 D-Day를 언급("수능까지 D-118, 오늘도 허리 지켜요").
- **데이터 모델**: `pg_goal.dday = {label, date}` — JSONB 동기화. 서버 변경 0.
- **예상 효과**: 화면에 '이유'를 박는다. 구현비 대비 체감 큰 전형적 기능.

#### P0-4. 캘린더 히트맵 농도 — 난이도 S

- **우리식 변형**: 기존 월 캘린더의 일별 셀 배경을 `watched_sec` 구간별 4단계 농도로. 자세 우수일(good% 높음)은 요정 아이콘 뱃지.
- **데이터 모델**: 변경 0 (`daily_stats` / `pg_daily` 그대로 렌더만 변경).
- **예상 효과**: 잔디 심기 심리. 빈칸을 채우려 앱을 켠다.

### P1 — 2주 내 현실적

#### P1-1. 과목별 서버 동기화 + 월간 과목 통계 — 난이도 M

- P0-2의 로컬 집계를 서버로. **테이블 1개 추가**:
  ```sql
  CREATE TABLE IF NOT EXISTS daily_subjects (
    account_id UUID REFERENCES accounts(id) ON DELETE CASCADE,
    date DATE NOT NULL,
    subject_id TEXT NOT NULL,
    watched_sec INT NOT NULL DEFAULT 0,
    good_sec INT NOT NULL DEFAULT 0,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    PRIMARY KEY (account_id, date, subject_id));
  ```
  - 과목 메타(name/color)는 accounts.data JSONB에 이미 있으므로 별도 subjects 테이블 불필요.
  - API는 기존 `daily`/`daily-pull` 패턴 복제(`daily-subjects`), GREATEST 병합 동일. 기기 여러 대 병합도 기존 규칙 그대로.
- 월 캘린더에 "과목 보기" 토글(그 달 과목별 누적 막대), 주간 리포트에 과목 비중 추가.

#### P1-2. 오늘 타임라인 (플래너 뷰) — 난이도 M

- 하루를 세로 타임라인으로: 과목 색 블록(공부 구간) + 자세 상태를 블록 테두리/패턴으로 오버레이. `pg_events`+`pg_subj_log` 머지 결과를 그대로 그리면 됨(새 데이터 없음).
- 열품타 플래너와 달리 **"몇 시에 자세가 무너졌는지"까지 보이는 플래너** — 유일무이.

#### P1-3. 리포트 공유 카드 (인증 훅) — 난이도 M

- 일/주 리포트를 캔버스로 이미지화(요정 캐릭터 + 오늘 시간 + 자세 % + 과목 도넛) → Web Share API / 다운로드. 열품타의 공스타그램 문화를 우리 카드로 태운다. **비개발 팀원 8인이 즉시 기여 가능한 영역**(카드 디자인·해시태그 운영).
- 데이터 모델 변경 0.

#### P1-4. 그룹 목표시간 + 오늘 달성 표시 — 난이도 M

- 그룹장이 "하루 목표 N시간" 설정 → 그룹 화면 멤버 카드에 오늘 달성 체크. 열품타의 '의무시간' 문화를 벌금 없이 가볍게.
- **데이터 모델**: `ALTER TABLE groups ADD COLUMN goal_sec INT` + 보드 API 응답에 멤버별 오늘 watched(이미 daily_stats에 있으므로 조인만). 난이도 M.

#### P1-5. 데이오프 ("요정의 휴식권") — 난이도 S

- 캘린더에서 쉬는 날 선언 → **스트릭이 안 끊김**. 월 3회 기본 제공 + 추가는 포인트로 구매(상점 품목 추가). 열품타의 데옾 + 스트릭 보호를 결합해 번아웃 이탈 방지.
- **데이터 모델**: `pg_dayoffs = ["YYYY-MM-DD", …]` JSONB 동기화, 스트릭 계산에서 해당 날짜 스킵. 서버 테이블 변경 0.

#### P1-6. 서비스 전체 주간 랭킹 (익명) — 난이도 M

- 그룹 밖 '전국' 훅. 주간 착석시간 TOP 100 (닉네임+요정 스킨만 노출). 기존 weekly_stats 집계 쿼리 1개 + 페이지 1개. 학년 카테고리 세분화는 P2.
- 어뷰징 가드는 이미 있는 MAX_GOOD_SEC(주당 상한) 재사용 — 열품타의 '20시간 불인정'과 동일 사상.

## 5. 한 페이지 요약 (비개발 팀원용)

**열품타가 뭐야?**
전국 수험생이 다 쓰는 공부 타이머 앱. 비결은 4단계 루프 — ① 진짜 공부한 시간만 정직하게 재고(순공시간) ② 그 기록을 예쁘게 보여주고(과목 색깔 플래너, 진해지는 달력) ③ 남들과 비교하게 하고(그룹·랭킹·"쟤 지금 공부 중") ④ 하루 쉬어도 돌아오게 한다(데이오프).

**우리는 뭐가 유리해?**
열품타의 순공시간은 "폰 화면을 안 봤다"는 간접 증거지만, 척추요정은 **웹캠으로 실제 앉아서 공부한 시간**을 잰다. 측정 자체가 더 정직하다. 게다가 우리만 **자세 데이터**가 있다 — "수학 할 때 자세가 제일 무너져요" 같은 리포트는 지구상에서 우리만 만들 수 있다.

**그래서 뭘 만들어? (시연 전 = P0)**
1. **오늘의 목표** — 목표 시간+자세% 정하고, 달성하면 요정이 칭찬+포인트.
2. **과목 타이머** — 과목 칩 눌러가며 공부, 오늘 리포트에 과목별 시간·자세.
3. **D-Day** — 화면 위에 "수능 D-118".
4. **달력 진하게** — 공부 많이 한 날일수록 달력이 진해짐.

**2주 안에 (P1)**: 과목 기록 서버 저장, 하루 타임라인(자세까지 보이는 플래너), **리포트 공유 카드(인스타 인증용 — 디자인·운영은 비개발 팀 몫!)**, 그룹 목표시간, 데이오프(쉬어도 스트릭 유지), 전체 주간 랭킹.

**안 만드는 것**: 앱 잠금(웹에선 불가능하고, 우리는 캠 감지로 이미 해결), 자동 사진 증명(영상은 서버로 안 보낸다는 원칙 위반), 커뮤니티 게시판(관리 불가), 유료 결제(아직 아님).

**한 줄 정리**: 열품타의 '기록→비교→복귀' 루프를 가져오되, 모든 조각에 자세와 요정을 붙여 "자세까지 지켜주는 열품타"를 완성한다.
