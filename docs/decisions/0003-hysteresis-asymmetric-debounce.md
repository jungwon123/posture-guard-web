# 0003. 히스테리시스 + 비대칭 디바운스 상태 전이

- 상태: accepted (2026-07, 프로토타입)

## 맥락

순간 점수로 바로 알리면 경계값 근처에서 알림이 깜빡거리고(핑퐁), 물병 집으려 잠깐 숙인 것까지 잡는다(오탐). 알림 피로 → 앱 꺼버림 → 실패.

## 결정

- **히스테리시스**: BAD 진입 임계(60)와 GOOD 복귀 임계(75)를 분리.
- **비대칭 디바운스**: BAD 진입은 20초 지속 필요(일시 동작 무시), GOOD 복귀는 5초(교정하면 빨리 보상).
- 개입도 즉시 최대가 아니라 시간 기반 에스컬레이션 (테두리 → 벨 → 비네트).

## 결과

- 알림의 신뢰도가 올라감 — 울리면 진짜 나쁜 자세가 지속된 것.
- 트레이드오프: 실제 나쁜 자세도 20초는 무통보. 의도된 지연이며 값은 튜닝 블록에서 조정.
