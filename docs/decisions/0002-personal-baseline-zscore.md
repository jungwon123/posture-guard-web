# 0002. 비율 정규화 신호 + 개인 기준 z-score 판정

- 상태: accepted (2026-07, 프로토타입)

## 맥락

절대 픽셀값·절대 각도 임계값은 체형, 카메라 위치·해상도, 앉은 거리에 따라 전혀 다른 의미가 된다.

## 결정

1. 신호는 신체 내부 비율로 정규화한다 (귀거리·어깨폭 기준). 예외는 `proximity`(귀거리 자체) 하나 — 카메라와의 거리 변화 자체가 신호이기 때문.
2. 판정은 5초 캘리브레이션으로 잡은 **개인 기준(μ, σ) 대비 z-score**로 한다. σ에는 하한(`SIGMA_FLOOR_FRAC`)을 둬 미동 없는 캘리브레이션으로 인한 z 폭발을 막는다.

## 결과

- 사용자·환경이 바뀌어도 재캘리브레이션만 하면 됨. 절대 임계값 튜닝 지옥 회피.
- 트레이드오프: 캘리브레이션 자세가 나쁘면 기준 자체가 오염됨 → 사용 순서에서 "바르게 앉은 뒤 c" 안내.
