# 0005. 시계 주입으로 리플레이·테스트 가능하게

- 상태: accepted (2026-07, 프로토타입)

## 맥락

디바운스·히스테리시스 튜닝을 실시간으로 검증하려면 매번 웹캠 앞에서 자세를 잡고 수십 초 기다려야 한다. 반복 불가능한 튜닝 루프.

## 결정

`StateMachine.update(score, now)`처럼 시간 의존 로직은 전부 `now`를 인자로 받는다 (`time.time()` 내부 호출 금지). 신호를 JSON으로 녹화해두고 `--replay`로 판정·상태 로직만 오프라인 재구동.

## 결과

- 튜닝 루프가 초 단위로 단축. 같은 입력으로 파라미터 A/B 비교 가능.
- 단위 테스트에서 가짜 시계로 전이 시나리오 검증 가능.
- 규칙: 새로 추가하는 시간 의존 로직도 반드시 시계를 주입받을 것 (`architecture/pipeline.md`).
