# 0004. 상태 전이만 기록, 프레임은 저장·전송 안 함

- 상태: accepted (2026-07, 프로토타입)

## 맥락

상시 웹캠 도구는 프라이버시 불안이 채택의 최대 장벽. 또한 통계 목적에는 프레임·점수 시계열이 과잉이다.

## 결정

- 영상 프레임은 어떤 형태로도 저장·전송하지 않는다. 처리는 전부 로컬·인메모리.
- SQLite에는 상태 전이 구간(state, started_at, ended_at)만 남긴다. 일일 통계는 이것으로 충분.
- 신호 녹화(`r`)는 튜닝 전용 opt-in이며, 산출물도 좌표 파생 수치일 뿐 영상이 아니다.

## 결과

- "카메라를 쓰지만 아무것도 안 남긴다"를 코드 구조로 보증 (`architecture/privacy.md` 불변식).
- 파생 산출물(profile/db/녹화)도 개인 데이터로 취급 — 커밋 차단 훅 대상.
