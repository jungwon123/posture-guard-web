# 🧚 척추요정 🪑

📚 공부하거나 💻 컴퓨터를 오래 하다 보면 자기도 모르게 목이 앞으로 쭉 나옵니다. 문제는 정작 본인은 그 순간을 모른다는 것입니다. 😵 목이 뻐근해지고 나서야 "아, 또 구부정하게 있었구나" 하고 깨닫습니다. 척추요정은 이걸 대신 봐주는 서비스입니다. 📷 웹캠으로 자세를 지켜보다가 무너지면 그때 딱 알려줍니다. 🔔

👉 써보려면: https://posture-guard-rust.vercel.app (설치 없이 링크로 바로 열립니다 ✨)

## 🤔 왜 만들었나요

자세를 챙겨준다는 앱은 이미 많습니다. 그런데 다들 오래 못 쓰는 이유가 있었습니다.

- ⏰ **시간마다 울리는 알림 앱** — 자세가 멀쩡할 때도 울려서 며칠 만에 꺼버리게 됩니다 🙉
- ⌚ **몸에 붙이는 센서 제품** — 사야 하고, 매일 착용하는 것도 귀찮습니다 💸
- ☁️ **영상을 서버로 보내 분석하는 서비스** — 내 모습이 어디론가 올라간다는 게 찝찝합니다 😨

그래서 우리는 세 가지를 지키기로 했습니다. 🎯

1. ✅ **진짜 무너졌을 때만 알립니다** — 잠깐 숙인 건 넘어가고, 나쁜 자세가 계속될 때만 알려줍니다
2. 🎁 **혼내지 않습니다** — 조용한 알림으로 시작해서 점점 세지고, 잘하고 있으면 오히려 포인트를 줍니다
3. 🔒 **영상은 밖으로 내보내지 않습니다** — 분석은 전부 내 기기 안에서 끝납니다

## ✨ 무엇을 할 수 있나요

🎥 기본은 실시간 감지입니다. 카메라로 코·귀·어깨를 따라가면서 지금 자세가 얼마나 바른지 0~100점으로 보여줍니다. 옆 화면에는 컴퓨터가 나를 어떻게 보고 있는지(뼈대 그림과 그래프)도 같이 나와서, 왜 점수가 깎였는지 눈으로 확인할 수 있습니다. 🦴

📏 처음에 "기준 등록"을 5초 합니다. 이게 중요합니다. 사람마다 체형도 다르고 카메라 위치도 달라서 "누구에게나 맞는 바른 자세" 같은 건 없습니다. 그래서 나의 바른 자세를 먼저 재두고, 이후에는 그 기준에서 얼마나 벗어났는지로 판단합니다. 👤

🔔 자세가 무너지면 알림이 오는데, 한 번에 시끄럽게 하지 않습니다. 처음엔 살짝, 계속 그러면 소리가 커지고, 더 오래 방치하면 화면 가장자리가 어두워집니다. 🌑 알림음은 네 종류 중에 고르거나 🎵 내가 좋아하는 노래를 넣을 수도 있고, 📳 진동 횟수도 정할 수 있습니다.

여기에 계속 쓰고 싶게 만드는 장치들을 얹었습니다.

- 🧚 **척추요정 캐릭터** — 자세에 따라 표정과 동작이 바뀝니다. 잘하면 웃고 😊, 무너지면 화내고 😠, 오래 방치하면 아파합니다 🤕
- 🪙 **포인트** — 바른 자세를 1분 유지할 때마다 쌓이고, 🛍️ 캐릭터 스킨이나 화면 테마를 살 수 있습니다
- 📊 **오늘 리포트** — 하루가 끝나면 바른 자세로 있었던 비율과 기록을 보여줍니다
- 👥 **그룹 랭킹** — 친구들끼리 코드로 모여서 이번 주 누가 자세를 더 잘 지켰는지 겨룰 수 있습니다 (열품타 느낌 🏆)

이 밖에 세세한 배려도 넣었습니다. 🙈 얼굴 보이는 게 싫으면 카메라 화면을 캐릭터로 덮을 수 있는데, 이때도 감지는 계속됩니다. 👁️ 눈 깜빡임을 세는 기능(베타)도 있어서, 화면을 오래 보다 눈을 너무 안 깜빡이면 눈이 건조해진다고 알려줍니다.

## 📱 기기마다 쓰는 법이 조금 다릅니다

솔직한 한계가 하나 있습니다. 🤖 안드로이드와 💻 컴퓨터는 앱을 뒤에 두고도 감시가 되지만, 🍎 아이폰은 애플 정책상 앱이 화면 밖으로 나가면 카메라가 꺼집니다.

- 💻 **컴퓨터(크롬)**: 작은 상태 창을 다른 창들 위에 띄워두고 작업하면 됩니다
- 🤖 **안드로이드**: 그냥 링크로 열어서 쓰면 됩니다. 알림·진동 다 됩니다
- 📲 **아이패드**: 화면을 반으로 나눠서(스플릿 뷰) 한쪽에 공부·인강, 한쪽에 척추요정을 둡니다
- 🍎 **아이폰**: 사파리로 열어 홈 화면에 추가한 뒤, 폰을 거치대에 세워 감시 전용으로 씁니다 📐

## ⚙️ 어떻게 자세를 알아챌까요

카메라에 들어온 화면 한 장 한 장을 이렇게 처리합니다.

1. 🔍 먼저 구글이 만든 **MediaPipe**라는 AI가 화면에서 코·귀·어깨 위치를 찾습니다
2. 📐 그 위치로 거북목 신호 네 가지를 계산합니다 — 머리가 앞으로 나왔는지, 고개를 숙였는지, 머리가 어깨 쪽으로 내려왔는지, 어깨가 말렸는지
3. 🎯 이 값들을 미리 재둔 내 기준과 비교해서, 나쁜 방향으로 벗어난 만큼 점수를 깎아 0~100점을 만듭니다
4. ⏱️ 이 점수가 낮은 상태가 얼마나 오래 이어지는지를 보고 "바른 자세 / 나쁜 자세 / 자리 비움"을 판단합니다
5. 📮 상태가 바뀌는 순간에만 알림을 보내고 기록합니다

💡 핵심은 두 가지입니다. 하나는 **남과 비교하지 않고 내 기준과 비교**한다는 것, 다른 하나는 **순간이 아니라 지속을 본다**는 것입니다. 이 둘 덕분에 알림이 시도 때도 없이 울리지 않습니다.

## 🛠️ 무엇으로 만들었나요

🖥️ **앞부분(화면)은 React로 만든 웹앱입니다.** ⚛️ React + Vite로 화면을 컴포넌트 단위로 나눠 만들었고, 카메라·감지처럼 실시간으로 도는 부분은 따로 떼어 관리합니다. 🧠 자세를 알아보는 AI는 서버가 아니라 **브라우저 안에서 직접** 돌아갑니다 (자세용 하나, 눈 깜빡임용 하나). ✅ 점수 계산이 맞는지 자동 테스트로 확인했고, 📦 홈 화면에 설치되는 앱처럼 동작하게 만들었습니다. ▲ 배포는 Vercel로 했습니다.

🗄️ **뒷부분(서버)은 그룹 랭킹만 담당합니다.** 처음엔 간편한 방식(서버리스)으로 만들었다가, 서버를 직접 다뤄보려고 구글 클라우드(GCP)의 가상 컴퓨터로 옮겼습니다.

| 부분 | 쓴 것 |
| --- | --- |
| 🖥️ 서버 | 구글 클라우드 가상 컴퓨터(VM, 서울) — 우리가 직접 관리 |
| ⚡ 프로그램 | Node.js + Express |
| 🐘 데이터 저장 | PostgreSQL (서버 안에만, 바깥엔 닫아둠) |
| 🔐 보안 연결 | Caddy + 자동 인증서(HTTPS) |
| 🎫 로그인 | 아직 없음 (닉네임만), 로그인은 마지막에 |

🛡️ 누구나 쓰는 서비스라, 나쁜 사용을 막는 장치(요청 횟수 제한, 그룹 정원, 점수 조작 방지 등)를 넣어뒀습니다.

## 🔒 개인정보를 어떻게 지키나요

이게 우리 서비스의 약속이자 다른 제품과 다른 점입니다. 🙅 **카메라 영상과 몸 정보는 절대 서버로 보내지 않습니다.** 서버로 가는 건 닉네임과 "이번 주 바른 자세 시간·포인트" 같은 숫자뿐입니다. 📴 인터넷을 꺼도 감지·알림·포인트는 다 됩니다 (그룹 랭킹만 인터넷이 필요합니다).

## 🧪 잘 되는지 어떻게 확인했나요

만들고 "잘 되겠지" 하고 넘기지 않았습니다.

- 🔁 같은 데이터를 두 가지 버전에 넣어서 판단 결과가 똑같은지 확인했습니다
- ✔️ 포인트·출석·상점 계산은 테스트 14개로 검증했습니다
- 🎚️ 자세 판단은 영상이 아니라 숫자만 녹화해두고, 기준을 바꿔가며 몇 번이든 다시 돌려봤습니다
- 🧱 서버도 나쁜 사용을 실제로 막는지 직접 확인했습니다
