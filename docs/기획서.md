# Posture Guard — 기획서

> 노트북 카메라로 **거북목 자세를 알아채서**, 자세가 무너졌을 때만 알려주는 프로그램.
> 문서 버전: v1.1 (2026-07-17) · 누구나 읽을 수 있게 쉬운 말로 쓴 버전

---

## 1. 어떤 문제를 풀려고 하나?

공부하거나 컴퓨터를 오래 하다 보면 나도 모르게 목이 앞으로 쭉 나온다. 문제는 **본인은 그 순간을 절대 모른다**는 것. 목이 아파진 다음에야 "아, 내가 계속 구부정했구나" 하고 알게 된다.

이미 나와 있는 방법들은 이런 단점이 있다:

- **"30분마다 스트레칭하세요" 알림 앱** → 자세가 멀쩡할 때도 울린다. 귀찮아서 며칠 만에 꺼버린다.
- **몸에 붙이는 센서 제품** → 돈 주고 사야 하고, 매일 붙이는 것도 일이다.
- **영상을 서버로 보내서 분석하는 서비스** → 내 카메라 영상이 인터넷으로 나간다는 게 찝찝하다.

그래서 우리가 내린 결론: **진짜로 자세가 무너졌을 때만, 처음엔 조용히, 계속 그러면 점점 세게** 알려줘야 사람들이 안 끄고 오래 쓴다.

## 2. 우리의 해결책 (한 줄)

**어차피 달려 있는 노트북 카메라**로, **영상은 아무 데도 저장하지 않으면서**, **"내 바른 자세"를 기준으로** 거북목을 감지해, **무너졌을 때만** 알려주는 프로그램.

## 3. 누가 쓰나?

| 순위 | 대상 | 어떻게 쓰나 |
|---|---|---|
| 1순위 | 공부·코딩을 오래 하는 학생 | 프로그램 켜두고 공부 → 자세 무너지면 알림 받기 |
| 2순위 | 재택근무하는 직장인 | 하루 동안 자세가 어땠는지 기록 보기 |
| 3순위 | 병원에서 자세 교정 권고받은 사람 | 교정이 잘 되고 있는지 확인 |

## 4. 주요 기능

### 4.1 실시간 감지 화면 (2분할)

화면이 둘로 나뉜다:

- **왼쪽**: 내 카메라 화면. 지금 상태(좋음/나쁨/자리비움)와 자세 점수(0~100점)가 표시된다.
- **오른쪽**: 컴퓨터가 나를 "어떻게 보고 있는지" 보여주는 화면. AI가 찾아낸 내 몸의 뼈대 그림과, 판단에 쓰는 5개 지점(코, 양쪽 귀, 양쪽 어깨)이 표시된다. 지금 어떤 부분 때문에 점수가 깎이는지 막대그래프로 실시간 확인 가능.

### 4.2 "내 기준" 등록 (캘리브레이션)

사람마다 체형이 다르고 카메라 위치도 달라서, "모두에게 통하는 바른 자세 기준" 같은 건 없다. 그래서 처음에 **바르게 앉은 상태로 `c` 키를 누르면 5초간 내 모습을 측정**해서, "이게 이 사람의 바른 자세"라는 기준을 만든다. 이후 모든 판단은 **그 기준에서 얼마나 벗어났는가**로 이뤄진다.

### 4.3 숨겨두고 쓰기 (미니 모드) + 알림

`h` 키를 누르면 큰 화면이 **작은 상태 표시줄**로 줄어든다. 구석에 치워두고 평소처럼 공부하면 된다. 자세가 무너지면 **화면 오른쪽 위에 알림**이 뜬다 (카톡 알림처럼).

### 4.4 점점 세지는 알림 (단계적 개입)

처음부터 시끄럽게 울리면 짜증 나서 꺼버린다. 그래서 살살 시작해서 점점 세게 간다:

| 단계 | 언제 | 무엇을 |
|---|---|---|
| 1 | 나쁜 자세 20초 지속 | 알림 1번 + 화면에 얇은 빨간 테두리 |
| 2 | 그 뒤로도 1분 계속 | 알림 한 번 더 + 소리 + 테두리 굵어짐 |
| 3 | 3분 계속 | 화면 가장자리가 어두워짐 (거슬려서 고치게 됨) |
| 복귀 | 자세 고치고 5초 유지 | "자세 복귀. 좋아요!" 칭찬 알림 |

### 4.5 기록

"몇 시부터 몇 시까지 나쁜 자세였다"는 **시간 기록만** 남긴다. 프로그램을 끄면 오늘 좋은 자세/나쁜 자세가 각각 몇 분이었는지 알려준다.

## 5. 어떻게 알아채는 걸까? (동작 원리)

컴퓨터는 카메라 영상 하나하나를 이렇게 처리한다:

```
① 몸 찾기      AI(구글 MediaPipe)가 화면에서 내 코·귀·어깨 위치를 찾는다
② 신호 계산    그 위치들로 "거북목 신호" 4가지를 계산한다
                - 얼굴이 화면에 가까워졌나? (거북목이면 머리가 앞으로 나옴)
                - 고개를 숙였나?
                - 머리가 어깨 쪽으로 내려왔나?
                - 어깨가 안으로 말렸나?
③ 점수 매기기  "내 바른 자세 기준"에서 나쁜 방향으로 벗어난 만큼 감점 → 0~100점
                (숨 쉬고 살짝 움직이는 정도는 감점 안 함)
④ 상태 판단    점수가 60점 아래로 20초 넘게 유지되면 → "나쁜 자세"로 판정
                75점 위로 5초 유지하면 → "좋은 자세"로 복귀
                ※ 잠깐 물건 줍느라 숙인 건 20초가 안 되니까 봐준다
⑤ 알림·기록    상태가 바뀌는 순간에만 알림을 보내고 기록한다
```

핵심 아이디어 2가지:

- **절대 기준이 아니라 "나만의 기준"**: 남과 비교하지 않고, 내 바른 자세와 지금을 비교한다.
- **순간이 아니라 "지속"**: 잠깐 숙인 건 무시하고, 계속 유지될 때만 진짜로 친다. 그래서 알림이 시도 때도 없이 울리지 않는다.

## 6. 사생활 보호 (제일 중요한 약속)

> **카메라 영상은 어디에도 저장하지 않고, 인터넷으로 보내지도 않는다.**

- 컴퓨터에 남는 건 숫자뿐이다: 내 기준값(숫자 몇 개), "몇 시~몇 시 나쁜 자세" 기록.
- 인터넷 연결 자체를 안 쓴다. 전부 내 컴퓨터 안에서만 처리된다.
- 그 숫자 파일들조차 실수로 인터넷(깃허브)에 올라가지 않도록 자동 차단 장치를 걸어놨다.

## 7. 무엇으로 만들었나?

| 부품 | 쓴 것 | 왜 |
|---|---|---|
| 몸 위치 찾기 | MediaPipe (구글의 무료 AI) | 인터넷 없이 내 컴퓨터에서 돌아감 |
| 카메라·화면 | OpenCV (영상 처리 도구) | 시제품 만들기에 충분 |
| 점수 계산 | 직접 만든 수식 | AI 학습 데이터가 필요 없음 — 통계로 해결 |
| 기록 저장 | SQLite (파일 하나짜리 미니 DB) | 서버가 필요 없음 |
| 언어 | Python 파일 1개 | 전체 흐름을 한눈에 볼 수 있음 |

## 8. 잘 되는지 어떻게 확인하나?

- **녹화 → 다시 재생**: `r` 키를 누르면 (영상이 아니라) 신호 숫자들만 녹화된다. 이 녹화를 가지고 "기준을 이렇게 바꾸면 판정이 어떻게 달라지지?"를 카메라 없이 몇 번이고 다시 실험할 수 있다.
- 오작동이 잦으면 기준을 느슨하게, 너무 둔하면 민감하게 — 이 조정을 녹화 데이터로 한다.
- 가짜 시나리오(좋은 자세 30초 → 거북목 30초 → ...)를 만들어 재생해봤고, 설계한 대로 정확히 판정되는 것을 확인했다.

## 9. 팀 구성 (9명)

개발 1명(전체 구현) + 비개발 8명. 각 역할은 **책임지는 질문 하나 + 주간 산출물 1개**로 정의한다.

| # | 역할 | 책임지는 질문 | 대표 산출물 |
|---|---|---|---|
| 1 | PM / 기획 리드 | 지금 뭐가 제일 중요한가? | 백로그, 주간 계획, 회의록 |
| 2 | 도메인 리서처 | 우리가 남들과 뭐가 다른가? | 경쟁 조사, 근거 자료 리포트 |
| 3 | UX 리서처 | 사용자는 어디서 불편해하는가? | 사용성 테스트 기록, 개선 목록 |
| 4 | QA 리드 | 지금 망가진 데 없는가? | 테스트 케이스, 버그 리포트 |
| 5 | 데이터 담당 | 감지가 얼마나 정확한가? | 녹화 수집→리플레이 결과→임계값 제안 |
| 6 | 디자이너 | 어떻게 보여야 하는가? | UI 시안, 로고, 발표 비주얼 |
| 7 | 테크니컬 라이터 | 처음 보는 사람이 이해할 수 있는가? | 사용자 가이드, 보고서 |
| 8 | 발표/데모 디렉터 | 5분 안에 설득되는가? | 데모 각본, 발표자료 |

※ 5번(데이터)은 이 프로젝트와 궁합이 특히 좋다 — 녹화/재생 구조 덕분에 코딩을 몰라도 "데이터 모으기 → 결과 정리 → 기준값 제안" 순서로 실질적인 기여를 할 수 있다.

## 11. 웹(PWA) 버전 계획 — 되는 것과 안 되는 것

지금은 컴퓨터에 설치하는 프로그램이지만, **웹사이트(설치형 웹앱, PWA)** 로 만들면 링크 하나로 누구나 바로 쓸 수 있다. 팀원 8명이 테스트하기도 훨씬 쉬워진다. 미리 조사한 결과:

### 되는 것 (컴퓨터 브라우저 기준)

- **감지·점수·판정**: 몸 위치를 찾는 AI(MediaPipe)가 브라우저 안에서도 돌아간다. 영상이 인터넷으로 나가지 않는 것도 그대로 지킬 수 있다.
- **알림**: 다른 탭을 보고 있어도 알림을 띄울 수 있다 (처음에 "알림 허용" 한 번만 누르면 됨).
- **뒤에서 감시**: 탭을 뒤로 보내도 카메라는 계속 작동한다. 어차피 우리는 1초에 한 번만 확인해도 충분해서 (20초 지속돼야 나쁜 자세니까) 성능 걱정도 없다.
- **미니 모드는 오히려 업그레이드**: "화면 위에 항상 떠 있는 작은 창"(PiP — 유튜브 미니 플레이어 같은 것)으로 만들 수 있다. 어떤 앱을 쓰고 있어도 구석에 상태가 보인다.

### 안 되는 것과 대신하는 방법

| 안 되는 것 | 왜 | 대신 이렇게 |
|---|---|---|
| 빨간 테두리·화면 어두워지기를 **다른 앱 위에** 표시 | 웹은 자기 페이지 밖을 못 건드림 | 페이지가 안 보일 땐 **알림을 반복**하는 걸로 대체 |
| 태블릿에서 완전히 숨기고 감시 | 아이패드는 화면에서 안 보이면 카메라를 꺼버림 | **화면 반쪽에 붙여두기**(스플릿 뷰)로 사용 — 공부 앱 옆에 상주시키는 방식 |
| 알림 소리 마음대로 바꾸기 | 브라우저 제한 | 페이지를 한 번이라도 클릭한 뒤엔 자체 소리 재생 가능 |

### 정리

- **컴퓨터**: 지금 기능 거의 그대로 + 설치 없이 링크로 배포. ✅
- **태블릿**: "몰래 감시"는 안 되고 "옆에 붙여두고 감시"는 됨 — 공부하면서 쓰는 우리 타깃(3번 참고)에겐 오히려 자연스러운 사용법. ⚠️
- 점수 계산·판정 로직은 수학이라 그대로 옮기면 되고, 지금 파이썬 버전은 "정답지" 역할로 남긴다 (같은 녹화 데이터를 두 버전에 넣어 판정이 같은지 확인).

## 12. 걱정되는 점과 대비책

| 걱정 | 대비 |
|---|---|
