# 페이지 구조 설계 (v3) — 멀티 페이지 + 소셜 기능

> 요구: 로그인·메인·상점·캐릭터·그룹 5페이지, 출석체크, 그룹원 실시간 자세 확인 + 경고 보내기.

## 0. 핵심 설계 결정

**페이지를 전환해도 카메라 감지는 계속되어야 한다.**
→ 라우터로 페이지를 언마운트하지 않고, **5개 페이지를 전부 마운트한 채 하단 탭으로 표시만 전환**한다 (display 토글).
카메라·엔진(app.js)은 어느 페이지에 있든 계속 돈다. 상점 구경 중에도 자세는 감시된다.

## 1. 페이지 구성 (하단 탭 5개)

### 🏠 메인
- **상단**: 핵심 기능 그대로 — 내 화면(카메라) + TRACKING, 컨트롤 버튼, 상태 메시지
- **출석 카드**: 이번 주 출석 도장(월~일), 연속 출석 일수. 카메라를 시작하면 자동 출석(+10P)
- **하단**: 탭 2개로 차트와 글을 따로 본다
  - **📊 차트 탭**: 오늘 시간대별 자세 — 시간마다 바른 자세(초록)/나쁜 자세(빨강) 누적 막대
  - **📝 기록 탭**: 오늘 요약 글(총 감시·바른 비율·최장 기록) + 상태 변화 로그 (몇 시 몇 분에 무너짐/복귀)
- 알림 설정·눈 깜빡임 패널도 메인 하단에 유지

### 👥 그룹
- 내가 속한 그룹 카드 (이름·코드·내 닉네임)
- **그룹 생성하기** 버튼 + 코드로 참여하기
- **랭킹: 획득 포인트 많은 순** (동점이면 바른 자세 시간 순)
- **멤버 실시간 상태**: 지금 공부 중인 친구 옆에 상태 점 — 🟢 바른 자세 / 🔴 나쁜 자세 / ⚪ 자리비움 / (회색) 오프라인
- **👉 콕 찌르기**: 친구가 나쁜 자세면 버튼을 눌러 경고 알림 전송 ("○○님이 자세 펴라고 콕!")
  - 같은 그룹만, 자기 자신 제외, 같은 사람에게 1분 1회 제한

### 🛍️ 상점
- **상단: 보유 포인트 크게**
- 캐릭터 스킨 목록 (가격·보유 여부·구매 버튼) + 테마 색

### 🧚 캐릭터
- 현재 장착한 캐릭터 미리보기 (움직이는 모습)
- 보유한 스킨 목록에서 **장착** / 테마 적용

### 👤 로그인
- 형태만 우선 (닉네임·비밀번호 입력 UI + "지금은 로그인 없이 써요" 안내 + 게스트로 계속)
- 실제 인증은 백엔드 로드맵 ③에서 연결

## 2. 데이터 흐름

| 데이터 | 저장 | 화면 갱신 |
|---|---|---|
| 자세 상태·점수 | 엔진(app.js) → DOM 직접 | 실시간 |
| 오늘 차트·기록 | localStorage `pg_events` | React가 30초마다 다시 읽음 |
| 출석 | `pg_attend_days` (날짜 배열, 신규) | 출석 카드가 읽음 |
| 포인트 | `pg_points` | 상점·캐릭터 페이지가 2초마다 읽음 |
| 그룹 랭킹+상태 | 서버 | 그룹 페이지 열 때 + 30초마다 |

## 3. 백엔드 확장 (VM API 추가)

새 테이블:
```sql
presence (member_id PK→members, state, updated_at)   -- 실시간 자세 상태
nudges   (id, to_member, from_nick, created_at)      -- 대기 중인 콕
```

새/변경 API:
| 메서드/경로 | 동작 |
|---|---|
| POST `/api/presence` {memberId, state} | 내 현재 상태 업로드 (엔진이 30초마다) |
| GET `/api/leaderboard` | **정렬을 points DESC로 변경** + 각 멤버의 state·마지막 접속 포함 (90초 지나면 오프라인 취급) |
| POST `/api/nudge` {fromId, toId} | 콕 저장. 같은 그룹 검증, 분당 1회 제한 |
| GET `/api/nudges?memberId=` | 나에게 온 콕 수령(반환 후 삭제) — 엔진이 30초마다 폴링 → 알림 표시 |

프라이버시: 서버에 가는 건 여전히 **상태 문자열(GOOD/BAD/AWAY)과 집계 숫자뿐.** 영상·좌표는 절대 없음.

## 4. 구현 방식 (프론트)

- `App.jsx`: 하단 탭 내비 + 페이지 5개 컨테이너(전부 마운트, `display` 토글)
- 새 React 컴포넌트: `LoginPage`, `AttendanceCard`, `PostureChart`(차트/기록 탭), `CharacterPage`, `BottomNav`
- 차트는 라이브러리 없이 CSS 막대 (시간별 GOOD/BAD 초 누적)
- 엔진(app.js) 추가: presence 업로드(30s), nudge 폴링(30s), 리더보드 렌더에 상태 점·콕 버튼
- `reward.js` attend(): 출석 날짜를 `pg_attend_days` 배열에도 기록 (출석 카드용)

## 5. 완성 기준

- 탭을 오가도 카메라·감지가 끊기지 않는다
- 메인: 차트 탭과 기록 탭이 따로 보인다, 출석 도장이 찍힌다
- 상점: 상단에 포인트, 구매하면 즉시 반영
- 캐릭터: 보유 스킨 장착 시 헤더·미니모드 캐릭터가 바뀐다
- 그룹: 포인트순 랭킹 + 멤버 상태 점 + 콕 찌르면 상대에게 알림 도착
- 로그인: 페이지가 뜨고 "게스트로 계속"이 동작한다
