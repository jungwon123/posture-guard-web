재료 — AI가 주는 좌표

MediaPipe가 초당 약 10회 주는 것: Pose 33개 점(화면 비율 2D + 미터 단위 3D), 얼굴 회전행렬(4×4), 홍채 랜드마크 10개. AI의 역할은 여기까지 — 아래의 모든 판단은 이 좌표들로 하는 수학이다.논문 채택

사용 점: 코(0), 귀(7·8), 어깨(11·12), 손목(15·16). 논문도 같은 BlazePose 33점 토폴로지에서 어깨 11·12번으로 거북목을 추론한다.

신호 A층 — 2D 비율 3종

핵심 설계: 모든 신호를 비율로 만들어 카메라 거리와 무관하게 만든다.

proximity = d귀     pitch = y코 − y귀중점d귀     roll어깨 = W어깨d귀
읽는 법화면에 다가가면 귀 사이 거리가 커지고, 고개를 숙이면 코가 귀보다 내려가고, 어깨를 말면 어깨너비가 귀 간격 대비 줄어든다. 셋 다 나눗셈(비율)이라 멀리 앉아도 값이 같다.자체 설계
ŝt = 0.3·st + 0.7·ŝt−1
읽는 법지수이동평균(EMA). 새 측정 30% + 직전 평균 70%를 섞어 잔떨림을 죽인다.자체 설계
2

z-점수와 점수 곡선

"정답 자세"는 없다. 캘리브레이션 5초(논문과 동일)로 만든 내 기준과의 편차만 잰다.

zk = ŝk − μkσk · dirk
읽는 법μ = 캘리브 평균, σ = 캘리브 표준편차. "내 평소 흔들림(σ)의 몇 배나 벗어났나"라서 체형이 달라도 공평하다. dir는 나쁜 방향을 +로 맞추는 부호. 논문은 평균만 저장하지만 우리는 σ까지 저장해 개인별 감도를 만든다.논문 개량
Pcore = Σk wk · max(0, zk − 1.2)      Score = 100 · e−Pcore
읽는 법z가 1.2(데드존) 이하면 무시, 넘는 만큼만 가중치 w = (근접 0.5, 고개숙임 0.10, 어깨말림 0.40)로 벌점을 쌓는다. 점수는 지수 감쇠 — 벌점 0이면 정확히 100점, 벌점이 커질수록 가파르게 떨어진다.자체 설계

신호 B층 — 3D 절대 지표 8종

A층의 약점(구부정하게 기준 등록하면 그게 정상이 됨)을 보완하는 절대 게이트. 미터 단위 3D 좌표를 어깨너비 W로 나눠 정규화한다. 각도는 논문과 같이 arctan으로 계산한다.논문 채택

신호공식잡는 자세마진 → 최대
headVertical(ȳ어깨 − ȳ귀) / W머리 가라앉음25%↓ 부터
headForward(z̄어깨 − z̄귀) / W거북목 전방이동(깊이)+0.10 → +0.30
shoulderTiltatan2(|Δy|, |Δx|)어깨 기울기+3° → +14°
shoulderSpanW / d귀어깨 말림(3D 폭 축소)6%↓ → 15%↓
headLateral(x̄귀 − x̄어깨) / W좌우 쏠림(양방향)±0.12 → ±0.30
headPitchatan2(r21, r22)고개 숙임(회전행렬)±35° → ±48°
headRollatan2(r10, r00)고개 갸웃(회전행렬)±10° → ±30°
handToFacemin d(손목, 코) / W턱괴기(고정 임계)0.65 → 0.35
yaw = atan2(−r20, √r002 + r102)
읽는 법얼굴 회전행렬 R의 성분에서 세 축 각도를 분해(Tait-Bryan). √항이 0에 가까우면(고개를 극단적으로 젖힘) 짐벌락이라 roll을 0으로 처리한다. 절대각의 관례 오프셋은 어차피 "캘리브 기준과의 편차"만 쓰므로 상쇄된다.자체 설계

고개 숙임 마진이 ±35°로 유난히 넉넉한 이유: 책·필기를 내려보는 것은 정상 공부 동작이라서다. 거북목 판정은 내려보기에 오염되지 않는 headForward·shoulderSpan·홍채 신호가 주로 담당한다.

홍채 닮음비 거리

사람 홍채의 실제 지름은 누구나 약 11.7mm(±0.5)로 일정하다 — 논문이 소개한 Depth Estimation 전제.논문 채택

s ∝ D홍채d   ⇒   r = ssref = drefd
읽는 법닮음비: 화면상 홍채 크기 s는 실제 지름 D(일정)에 비례하고 거리 d에 반비례한다. 그래서 기준 대비 크기 비율 r이 곧 "얼마나 가까워졌나" 비율이다. 논문은 카메라 캘리브레이션으로 절대 cm를 구하지만, 우리는 비율만 써서 그 단계를 없앴다 — 기기 화각·초점거리 무관.논문 개량
근접 = T(r − 1; 0.15, 0.40)
읽는 법홍채가 기준보다 15% 이상 커져야(=그만큼 가까워져야) 감점 시작, 40% 초과분에서 최대. 멀어지는 쪽은 무시(비대칭). T는 5절의 램프 함수.논문 개량
B = WimgWimg,ref − 1      거북목 = { 0 if B > 0.08,  아니면  T(r − 1 − max(B, 0); 0.10, 0.30) }
읽는 법이 뺄셈이 핵심 아이디어. B는 몸통(이미지상 어깨너비)이 가까워진 비율. 얼굴이 가까워진 양에서 몸이 가까워진 양을 빼면 "머리만 앞으로 나온 순수 거북목"이 남는다. 몸 전체가 8% 이상 다가왔으면 그건 근접이 담당하므로 0.자체 설계

데드존-램프 공통형

3·4절의 모든 신호가 같은 꼴의 함수를 통과한다.

T(x; m, F) = min( max(x − m, 0)F, 1.5)
읽는 법편차 x가 마진 m 이하면 0(잠깐의 흐트러짐은 무시), 넘으면 램프폭 F에 비례해 커지고, 1.5에서 포화(한 신호가 판을 다 뒤집지 못하게 상한). 경첩(hinge) 함수라고도 부른다.자체 설계

One-Euro 필터 — 속도 적응 스무딩

"가만히 있을 땐 정밀하게, 움직일 땐 즉시" — 필터 세기를 속도에 따라 바꾼다.

fc = fmin + β|ẋ̂|      α = 11 + τ/Δt,  τ = 12πfc      x̂t = αxt + (1−α)x̂t−1
읽는 법차단주파수 fc가 변화 속도 |ẋ̂|에 비례해 올라간다. 속도 0이면 강한 평균(떨림 제거), 빠른 움직임이면 α가 1에 가까워져 즉시 반영(지연 없음). 깊이(Z) 신호는 노이즈가 커서 fmin을 더 낮게(더 강한 스무딩) 잡았다.자체 설계

결합 — 상관 신호의 중복 감점 완화

논문의 상관분석: 목-머리 0.95, 목-어깨 0.72, 어깨-머리 0.70. 구부정해지면 셋이 같이 움직인다는 뜻 — 그냥 더하면 한 번 무너진 자세를 서너 번 중복 감점한다.논문 채택

Pabs = cmax + 0.35 · (Σci − cmax)
읽는 법가장 큰 기여 신호는 100% 반영, 나머지 상관 신호들은 35%만 보조 증거로. 논문은 상관을 발견만 했고, 그걸 감점 수식으로 옮긴 건 우리다. "가장 아픈 부위"(cmax의 신호)가 요정의 부위별 반응·말풍선 멘트를 정한다.논문 개량
S = Score · e−Pabs
읽는 법최종 점수 = A층 점수 × B층 지수 감쇠. B층 벌점이 0이면 곱해도 그대로(무영향), 커질수록 점수를 깎는다. 두 층이 독립적으로 켜지고 꺼질 수 있는 안전한 결합.자체 설계

상태머신 — 즉시 판정하지 않는다

논문의 GREEN/YELLOW/RED 신호등 구조를 가져오되, 각도 즉시 판정 대신 점수 문턱 + 지속시간 + 히스테리시스로 바꿨다. 주의 단계의 근거는 논문 그대로: 목하중 약 5kg이 두 배(약 12kg)로 늘기 시작하는 구간의 조기 경고.논문 개량

전이조건지속동작
GOOD → 주의S < 732.5s요정 표정만(무음)
GOOD → BADS < 607s급락은 곧장
주의 → BADS < 605s이미 경고 중이라 빠르게
복귀 → GOODS ≥ 753s진입(60)과 다른 문턱
미검출 → 자리비움S = ∅10s시간 집계 제외
BAD 방치—20s / 60s알림 → 화면 비네트 단계 상승
히스테리시스란: 나빠지는 문턱(60)과 회복 문턱(75)을 다르게 두는 것. 문턱이 하나면 점수가 그 근처에서 흔들릴 때 GOOD↔BAD가 초단위로 튄다. 문턱 사이 15점의 완충지대가 상태를 안정시킨다.

28일 선형회귀 · SFU 대역폭

한 달간 교정되고 있는가 — 최소제곱 기울기 논문 채택

b = Σ(xi − x̄)(yi − ȳ)Σ(xi − x̄)2
읽는 법x = 경과일, y = 그날의 바른자세 %. 최근 28일(논문과 같은 창)의 점들에 가장 잘 맞는 직선의 기울기 b. b > 0이면 좋아지는 중이고, 주간 변화량은 7b %p. 통계 페이지의 월간 추세 배너가 이 값이다.

왜 SFU인가 — 업로드 대역폭 자체 설계

Umesh = (N − 1) · b      USFU = b      E서버 = N(N − 1) · b
읽는 법N명 방, 1인 비트레이트 b일 때 내 업로드: mesh는 (N−1)배로 늘고 SFU는 항상 1개. 예: 6명 방, b = 1Mbps → mesh 업로드 5Mbps(폰이 못 버팀) vs SFU 1Mbps. 대신 전달 부담 E가 서버로 옮겨간다 — 이 한계를 직접 실측하고 SFU로 갈아탄 것이 우리의 3단 서사다.
