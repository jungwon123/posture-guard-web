# 척추요정 기능 고도화 가이드 (고1용 · 코딩 몰라도 OK)

> "고도화"는 어려운 말이 아니에요. **지금 있는 기능을 더 재밌게, 더 오래 쓰게, 더 친절하게 만드는 것**입니다.
> 여러분은 코드를 안 짜도 됩니다. 대신 **"이렇게 바꾸면 좋겠다"를 개발자가 바로 만들 수 있게 적어주는 것**이 여러분의 일이에요.

---

## 0. 딱 하나만 기억하기

좋은 개선안의 기준은 하나예요:

> **"개발자가 이 종이만 보고, 나한테 안 물어보고 만들 수 있는가?"**

그래서 "예쁘게 해줘", "재밌게 해줘" 같은 말은 ❌. 대신 **숫자·화면·상황**으로 적어요.
- ❌ "알림 좀 다양하게 해줘"
- ✅ "밤 9시 이후에는 알림 소리를 딩동 대신 조용한 진동 1번으로 바꾼다"

이 차이만 알면 여러분은 이미 절반은 한 거예요.

---

## 1. 어떤 기능이든 개선하는 4단계

무슨 기능을 맡든 이 순서로 생각하면 됩니다.

| 단계 | 질문 | 예시 (포인트 기능) |
|---|---|---|
| ① 지금 어때? | 지금은 어떻게 되어 있지? | 바른 자세 1분에 1포인트를 준다 |
| ② 뭐가 아쉬워? | 심심하거나 불편한 점은? | 매일 똑같아서 3일 지나면 재미없다 |
| ③ 어떻게 바꿔? | 더 있으면 좋겠는 걸 **구체적으로** | 3일 연속 쓰면 그날 포인트 2배 (스트릭 보너스) |
| ④ 종이에 적기 | 개발자용 "개선 카드" 작성 | (아래 템플릿) |

**팁**: ②번에서 막히면 이렇게 물어보세요 — *"내가 이 앱을 3일 쓰고 지운다면, 그 이유가 뭘까?"* 그 이유를 없애는 게 곧 개선 아이디어예요.

---

## 2. 기능별 개선 아이디어 씨앗 + 완성 예시

여러분이 맡은 기능이 아래 셋 중 하나일 거예요. 각 기능마다 **생각 씨앗(질문)** 과 **완성 예시 1개**를 줍니다. 예시를 그대로 따라 여러분 아이디어로 카드 1장을 만들면 성공.

---

### 🔔 기능 A — 알림 (자세 무너졌을 때 알려주기)

**지금 상태**: 소리/진동 선택, 알림음 4종, 내 노래 넣기, 진동 횟수 조절 가능.

**생각 씨앗**
- 알림이 올 때 기분이 어떨까? 짜증 안 나는 알림은 어떤 모습일까?
- 항상 똑같은 알림 대신, 상황마다 다르면 어떨까? (시간대? 며칠째 나쁜 자세인지?)
- 알림 문구가 매번 똑같으면 지겹지 않을까?
- 자세가 좋을 때도 가끔 칭찬 알림이 오면 어떨까?

**✅ 완성 예시 — "시간대별 알림 세기"**

| 항목 | 내용 |
|---|---|
| 무엇을 바꾸나 | 시간대에 따라 알림 방식을 자동으로 바꾼다 |
| 지금은 | 하루 종일 같은 소리·진동으로 알림 |
| 이렇게 바꿔요 | 낮(오전 9시~오후 6시)엔 소리+진동, 저녁(6~9시)엔 소리만, 밤(9시 이후)엔 진동 1번만 |
| 왜 좋아요? | 밤에 큰 소리가 나면 가족이 깨거나 놀란다. 시간대에 맞으면 안 꺼버리고 계속 쓴다 |
| 화면/동작 자세히 | 알림 설정에 "시간대 자동" 스위치 추가. 켜면 위 규칙대로 작동. 끄면 지금처럼 항상 같음 |
| 예외 상황 | 스위치가 꺼져 있으면? → 지금처럼 동작 / 새벽에 자세 감지되면? → 진동 1번만 |
| 다 됐는지 확인 | 밤 10시에 자세 무너뜨리면 소리 없이 진동 1번만 온다 |

---

### 🎮 기능 B — 계속 쓰게 만들기 (포인트·상점·캐릭터·리포트)

**지금 상태**: 바른 자세 1분에 1포인트, 출석 보너스, 상점(스킨·테마), 척추요정이 나쁜 자세에 화남, 오늘 리포트.

**생각 씨앗**
- 게임은 왜 계속 하게 될까? (레벨업? 수집? 경쟁? 매일 다른 미션?)
- 며칠 연속 쓰면 상을 주면 어떨까? (연속 출석 = 스트릭)
- 캐릭터가 그냥 화만 내는 대신, 내가 잘하면 **자라거나 진화**하면 어떨까?
- 상점에 살 게 더 있으면? (배경, 효과음, 칭호, 뱃지…)
- 오늘 리포트에 지난주랑 비교 그래프가 있으면 뿌듯하지 않을까?

**✅ 완성 예시 — "척추요정 진화"**

| 항목 | 내용 |
|---|---|
| 무엇을 바꾸나 | 포인트가 쌓이면 척추요정이 단계별로 진화한다 |
| 지금은 | 척추요정은 상태(좋음/나쁨)에 따라 표정만 바뀐다. 성장은 없다 |
| 이렇게 바꿔요 | 누적 포인트로 진화: 알(0P) → 아기요정(50P) → 요정(200P) → 빛나는 요정(500P) |
| 왜 좋아요? | "다음 단계 보고 싶어서" 계속 쓰게 된다. 내 노력이 눈에 보인다 |
| 화면/동작 자세히 | 헤더 캐릭터가 단계에 맞는 모습으로 표시. 진화하는 순간 "축하! 요정이 자랐어요" 알림 + 반짝 효과 |
| 예외 상황 | 포인트를 상점에서 써도 진화 단계는 안 내려간다(누적 기준) / 최고 단계면? → 그대로 유지 |
| 다 됐는지 확인 | 포인트가 50이 되는 순간 아기요정으로 바뀌고 축하 메시지가 뜬다 |

> 💡 이 예시는 그림이 더 필요해요 — 디자이너 친구에게 "알/아기요정/요정/빛나는요정 4개 그림"을 부탁하는 것까지가 이 카드의 일부예요.

---

### 👥 기능 C — 같이 쓰기 (그룹·랭킹, 열품타 느낌)

**지금 상태**: 그룹 코드로 가입, 이번 주 "바른 자세 시간" 랭킹.

**생각 씨앗**
- 열품타나 게임에서 친구랑 같이 하면 왜 더 열심히 하게 될까?
- 랭킹만 보는 것 말고, 친구끼리 **주고받을 것**이 있으면? (응원? 콕 찌르기?)
- 혼자 목표 말고 **다 같이 목표**가 있으면? (우리 그룹 이번 주 합쳐서 100시간)
- 반 대항, 학년 대항처럼 그룹끼리 붙으면 어떨까?

**✅ 완성 예시 — "자세 콕 찌르기"**

| 항목 | 내용 |
|---|---|
| 무엇을 바꾸나 | 그룹 친구가 나쁜 자세일 때 "콕 찌르기"로 응원(알림)을 보낸다 |
| 지금은 | 랭킹 숫자만 본다. 친구끼리 주고받는 건 없다 |
| 이렇게 바꿔요 | 랭킹 목록에서 친구 옆 "👉 콕" 버튼 → 그 친구에게 "○○님이 자세 펴라고 콕 찔렀어요!" 알림 |
| 왜 좋아요? | 서로 챙겨주는 재미. 혼자면 포기해도 친구가 찌르면 다시 앉게 된다 |
| 화면/동작 자세히 | 리더보드 각 줄에 콕 버튼. 한 사람에게 하루 3번까지. 받으면 화면 배너 + 진동 |
| 예외 상황 | 나 자신은 못 찌른다 / 하루 3번 넘으면 버튼 회색 / 상대가 앱을 꺼놨으면? → 다음에 켤 때 표시 |
| 다 됐는지 확인 | 친구 옆 콕 버튼을 누르면 그 친구 폰에 응원 알림이 뜬다 |

## 3. 개선 카드 빈 템플릿 (복사해서 쓰기)

여러분의 아이디어를 이 7칸에 채우면 끝이에요. 7번(다 됐는지 확인)이 제일 중요해요 — 이게 있어야 "완성"의 기준을 서로 똑같이 생각해요.

```
┌─────────────────────────────────────────────┐
│ 1. 무엇을 바꾸나 (기능 이름):                    │
│ 2. 지금은 이래요:                               │
│ 3. 이렇게 바꿔요 (한 문장):                      │
│ 4. 왜 좋아요? (안 하면 생기는 문제):              │
│ 5. 화면/동작 자세히 (숫자·위치·상황):             │
│ 6. 예외 상황 (이럴 땐? 3개 이상):                │
│ 7. 다 됐는지 확인 (눈으로 볼 수 있는 문장):        │
│ (그림 필요하면) 디자이너에게 부탁할 그림:          │
└─────────────────────────────────────────────┘
```

## 4. 이렇게 하면 안 돼요 (흔한 실수)

- ❌ **두루뭉술**: "알림 좋게" → 뭘 어떻게? 개발자가 못 만듦
- ❌ **말로만 전달**: 회의 때 말하고 안 적음 → 다음 날 아무도 기억 못 함. **무조건 카드에 적기**
- ❌ **한 카드에 여러 개**: "포인트도 늘리고 상점도 바꾸고 캐릭터도…" → **한 카드 = 한 개선**
- ❌ **좋은 자세 벌주기**: 나쁜 자세에 포인트 깎기 → 사람들이 짜증나서 앱을 지움. 상은 주되 벌은 조심
- ❌ **예외 안 쓰기**: 잘 될 때만 생각 → "0이면? 처음이면? 인터넷 끊기면?"까지 적어야 완성

---

## 5. 카드 다 만들면?

1. 팀 폴더(또는 공유 문서)에 올린다
2. 리더가 확인 → 개발자에게 전달
3. 개발자가 "질문 있음" 또는 "OK, 만들게요(난이도 상/중/하)"로 답한다
4. 질문 있으면 **말로 답하지 말고 카드를 고쳐서** 다시 낸다
5. 질문이 0개가 되면 개발 시작 🎉

### 오늘 당장 할 일

1. 내가 맡은 기능(A/B/C) 확인
2. "생각 씨앗" 질문에 답하며 아이디어 3개 쏟아내기 (많을수록 좋아요)
3. 그중 제일 좋은 1개로 **개선 카드 1장** 완성
4. 카드 제출
