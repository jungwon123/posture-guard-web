## P0 — 사용 흐름이 끊기는 결함 (즉시, 예상 반나절)

### P0-1. 카메라 권한 거부 후 복구 불가 (#7)
- **관찰**: "Permission dismissed" 노출 → 거부 후 [공부 시작]을 눌러도 무반응·무안내.
- **원인 추정**: getUserMedia 실패(NotAllowedError/dismissed)를 구분 처리하지 않고 조용히 실패. 재시도 경로 없음.
- **대응 방향**: ① 실패 유형별 오버레이 — 거부: "카메라 허용이 필요해요" + 브라우저별 재허용 방법(주소창 자물쇠 → 카메라 허용) + [다시 시도] 버튼, 일시 닫음(dismissed): 즉시 재요청 버튼 ② [공부 시작]은 어떤 상태에서도 무반응 금지(항상 피드백) ③ 영문 오류 문구 노출 제거.
- **검증**: 폰·노트북에서 거부→재허용→시작 성공까지. 설정에서 영구 차단한 상태도.

### P0-2. 화면 공유 껐다 켜면 홈 카메라 정지 (#23)
- **관찰**: 함께하기에서 공유 on→off 후 홈으로 오면 카메라 화면 안 보이고 감지도 멈춤.
- **원인 추정**: 그리드가 홈 화면 `#cam` 스트림 트랙을 **재사용 발행** → unpublish 시 트랙이 stop되어 엔진 스트림까지 죽는 사이드이펙트 (GroupGridRoom publishTrack/unpublishTrack 경로).
- **대응 방향**: 발행 시 `track.clone()`으로 사본 발행(원본 보존) 또는 unpublish 옵션으로 stop 방지 + 홈 복귀 시 트랙 ended 감지→기존 acquireCamera 자동 재획득 가드에 연결.
- **검증**: 공유 on→off→홈 복귀 후 감지·타이머 지속, 3회 반복. 폰 2대 그리드에서도.

### P0-3. 카카오톡 인앱 브라우저에서 구글 로그인 오류 (#1, 삼성폰)
- **관찰**: 카톡 링크로 열면 구글 로그인 오류 → 시작 불가.
- **원인**: 구글이 인앱 WebView OAuth를 차단(disallowed_useragent) — 우리 버그가 아니라 정책. 공유 링크 유입(팀원 초대)의 첫인상이라 치명적.
- **대응 방향**: ① 인앱 브라우저 UA 감지(KAKAOTALK 등) → 상단 배너 "카카오톡 안에서는 구글 로그인이 막혀요 — 외부 브라우저로 열기" (안드로이드 intent:// 스킴, iOS 안내 문구) ② 이메일 로그인은 인앱에서도 동작함을 함께 안내(차선 경로 확보).
- **검증**: 삼성폰 카톡에서 링크 열기 → 배너 → 외부 브라우저 전환 → 구글 로그인 성공.
